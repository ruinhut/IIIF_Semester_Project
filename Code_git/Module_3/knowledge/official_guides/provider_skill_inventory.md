# Official IIIF Provider Workflow and Skill Inventory

Checked: `2026-10-08`; source revision: `c94b51bc335c6050667a536f2ba737807b92f8dc`.

This inventory transcribes official guide instructions into candidate skills. A candidate is not executable knowledge until its complete HTTP, JSON, and IIIF chain has been validated.

## Generic skill catalogue

| Skill | Meaning | Status |
|---|---|---|
| filtered-search-result-enumeration | Traverse a provider's IIIF-filtered result pages and retain item-record URLs. | candidate |
| record-page-manifest-link-extraction | Extract declared Manifest URLs from item-page links, data attributes, JSON-LD, metadata fields, and inline configuration. | partial |
| viewer-configuration-manifest-extraction | Read Mirador, Universal Viewer, or custom-viewer configuration and request parameters to recover Manifest URLs. | candidate |
| record-identifier-to-manifest-template | Transform a documented item identifier into one or more Manifest URL templates and validate every result. | implemented_as_part_of_paginated_json_identifiers_to_manifest_templates |
| catalogue-api-identifier-enumeration | Page through a structured catalogue API, extract item identifiers, and hand them to a validated Manifest template. | implemented_as_paginated_json_identifiers_to_manifest_templates |
| iiif-collection-traversal | Traverse Presentation 2/3 Collections and their pagination or child collections. | implemented |
| wikidata-p6108-query | Query Wikidata property P6108 and validate returned Manifest URLs. | candidate |
| image-api-filename-resolution | Resolve documented filename or identifier templates to IIIF Image API info.json resources without misclassifying them as Presentation Manifests. | candidate |
| legacy-platform-route-review | Recheck redirects, replacement catalogues, archived documentation, and current APIs before encoding a route for a migrated site. | investigation_only |
