## 获取方式

- BSB：官方指南明确给出的原生 IIIF Collection，跟随服务器提供的 `next` 游标。另行请求了实际下一页，确认可用。
- Rumsey：LUNA 分页搜索 JSON → `results[].iiifManifest` → 逐个验证。本次 20 个样本来自两页各 10 条结果。
- 梵蒂冈：目录 HTML 声明分库接口 → JSON `fond[].shelfmark` → 标准 Manifest 模板。保存 83 个目录声明的分库入口，本次在 Capp.Giulia 分库验证 20 个 Manifest；未声称所有分库均已测试。

三种方法复用现有解析器，本次没有新增机构专用 Python 分支。旧 EPFL、Chicago 和前两批配方全部保留，且与修改前备份逐项相同。
