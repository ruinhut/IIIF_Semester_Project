# 中期报告流程图素材

对应 `IIIF项目中期报告_2026-11-02.md` 中的图1-4。

| 文件前缀 | 展示主题 |
|---|---|
| `01_pipeline_overview` | Module 1-8 整体数据流与最终交付 |
| `02_module3_current_design` | 当前发现方法、知识配置与运行流程外的 AI 辅助调查 |
| `03_linked_output_contract` | 文献、图像、OCR 画像和机构参考文本的 ID 关联 |
| `04_rights_and_reference_delivery` | 研究保留、公开再利用子集和参考文本下载目录分流 |

每张图提供 PNG、SVG 和 DOT 三种格式。PNG 用于直接插图，SVG 为矢量图，DOT 为可编辑的 Graphviz 源码。重建脚本位于报告目录的 `tools/build_midterm_figures_20261102.py`。

图中展示的是当前能力。M3 的并列方法不是固定执行顺序，也不表示每个机构无上限地穷举全部路线。虚线表示调查结果或配置传递，没有运行时 AI 自动调查闭环。

图4中权利资格与参考文本可用性是独立维度，目录分流针对成功下载的图片。unknown/exclude 不等同于无参考文本，有参考文本也不等同于可公开传播。

报告中的可选图5（机构案例链路）、可选图6（未来 AI 闭环）以及两张统计图在本次只给出设计要求，没有作为已绘制素材打包。
